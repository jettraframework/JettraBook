## OpenLiberty


OpenLiberty , auspiciado por IBM, es un marco de trabajo ligero diseñado para la creación de microservicios. Puede encontrar más informaciçon en su página oficial [https://openliberty.io/](https://openliberty.io/). 



## Microprofile Starter


En este capítulo, vamos a desarrollar un proyecto usando Microprofile Starter, que se puede encontrar en [https://start.microprofile.io/](https://start.microprofile.io/).


En la página web, introduzca los valores que se indican a continuación

![](figura_17_00.png)


```
groupId: com.jmoordbcore


artifactId: capitulo17


MicroProfile Version: 5.0


Java SE Version: Java 11


Build Tool: Maven


Examples for specifications: Config, Health, Fault Tolerance, Metrics, OpenAPI 



```

Pulse el botón **Download**. Cuando la descarga esté completa, extraiga el archivo capitulo17.zip. Luego, abra el proyecto en su IDE y póngalo en marcha en modo desarrollador.


```shell

mvn liberty:dev

```

El proceso de descarga de dependencias y ejecución de la aplicación se inicia. Al finalizar este proceso, puede observar los puertos que están disponibles:


 * Liberty server HTTP port: [ 9080 ]
 * Liberty server HTTPS port: [ 9443 ]
 * Liberty debug port: [ 7777 ]



Ejecute la consulta en [http://localhost:9080/data/hello](http://localhost:9080/data/hello) para obtener el resultado.


2. Defina la clase MongoDBProducer.java.


```java
@ApplicationScoped
@DateSupport( )
public class MongoDBProducer implements Serializable {

    @Inject
    private Config config;
    @Inject
    @ConfigProperty(name = "mongodb.uri")
    private String mongodburi;
    
    @Produces
    @ApplicationScoped
    public MongoClient mongoClient() {
        MongoClient mongoClient = MongoClients.create(mongodburi);
       return mongoClient;
    }

    public void close(@Disposes final MongoClient mongoClient) {
        mongoClient.close();
    }


}


```

6. Define la clase EstudianteController que contendrá los endpoints.


```java

@Path("estudiante")
public class EstudianteController {

    @Inject
    EstudianteRepository estudianteRepository; 

    @GET
    @Produces(MediaType.APPLICATION_JSON)
    public List<Estudiante> findAll() {
        return estudianteRepository.findAll();
    }

    @GET
    @Path("{idestudiante}")
    public Estudiante findByIdestudiante(@PathParam("idestudiante") String idestudiante) {
        return estudianteRepository.findByPk(idestudiante).orElseThrow(
               () -> new WebApplicationException("No hay estudiante con idestudiante " + idestudiante, Response.Status.NOT_FOUND));


    }


    @POST
    public Response save(@RequestBody(description = "Crea un nuevo estudiante.", content = @Content(mediaType = "application/json", schema = @Schema(implementation = Estudiante.class))) Estudiante estudiante) {

        return Response.status(Response.Status.CREATED).entity(estudianteRepository.save(estudiante)).build();
    }

    @PUT
    public Response update(

            @RequestBody(description = "Actualiza un nuevo estudiante.", content = @Content(mediaType = "application/json", schema = @Schema(implementation = Estudiante.class))) Estudiante estudiante) {
        return Response.status(Response.Status.CREATED).entity(estudianteRepository.update(estudiante)).build();
    }


    @DELETE
    @Path("{idestudiante}")
    public Response delete(@PathParam("idestudiante") String idestudiante) {

        estudianteRepository.deleteByPk(idestudiante);
        return Response.status(Response.Status.NO_CONTENT).build();
    }


    @GET
    @Path("findbynombre")
    @Produces(MediaType.APPLICATION_JSON)
    public List<Estudiante> findByNombre(@QueryParam("nombre") String nombre) {
        return estudianteRepository.findByNombre(nombre);
    }
}

```
