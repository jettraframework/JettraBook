## Documentos Embebidos y Referenciados

Como se mencionó previamente, un documento embebido es aquel que alberga otro documento dentro de sí mismo.

Por otro lado, un documento referenciado es aquel que establece una referencia a otro documento que se encuentra en una colección distinta, identificado por un campo clave marcado con la anotación @Id.

Ahora, vamos a mostrar un ejemplo práctico:


La entidad Animal, que se presentará a continuación, demuestra cómo se definen las entidades referenciadas usando @Referenced y las entidades embebidas utilizando la anotación @Embedded:


```java

@Entity
public class Animal {

 @Id(strategy = GenerationType.AUTO)
 private Long idanimal;
 @Column
 private String animal;
 @Column
 private String color;
 @Column 
 private Long edad;
 @Column
 private Date fechaalimentacion;
 
 @Embedded
 private Alimentacion alimentacion;
 
 @Embedded
 private List<Enfermedad> enfermedad;
 
 @Referenced(from = "grupo",localField = "idgrupo",typeReferenced = TypeReferenced.REFERENCED)
 private Grupo grupo;

 @Referenced(from="zoo",localField = "idzoo",typeReferenced = TypeReferenced.REFERENCED)
 private List<Zoo> zoo;

//..
}

```

## Gestión de Repositorios

Los repositorios deben definirse únicamente para las entidades que se han declarado con @Entity o @ViewEntity. Estos repositorios permiten realizar operaciones sobre los documentos de una colección.

Además, es crucial establecer el repositorio AutogeneratedRepository. Este se encarga de administrar los incrementos automáticos de los campos que se han definido con la anotación @Id, tal como se ilustra en el siguiente ejemplo:


```java

@AutosecuenceRepository(entity = Autosequence.class, jakartaSource = JakartaSource.JAKARTA)
public interface AutogeneratedRepository {

    @Autogenerated()
    public Long generate(String database, String collection);

}

```
Después de completar los pasos anteriores, el siguiente paso es crear el repositorio GrupoRepository:


Se requiere la definición de cuatro métodos en el repositorio, los cuales se detallan a continuación:

* Implementar búsquedas por fecha utilizando la anotación @Query.

* Realizar búsquedas filtradas por edad, donde la edad sea mayor que un valor específico, utilizando paginación.

* Implementar búsquedas por edad, donde la edad sea mayor que un valor específico, con la adición de paginación y ordenación.

* Búsquedas por edad mayor que con paginación y ordenación

* Crear un método que ejecute un 'ping' para verificar la conexión con la base de datos.

```java

@Repository(entity = Animal.class, jakartaSource = JakartaSource.JAKARTA)
public interface AnimalRepository extends CrudRepository<Animal, Long> {

    @Query(where = "fechaalimentacion .eq. @fechaalimentacion")
    public List<Animal> queryByFecha(@IncludeTime Date fechaalimentacion);

    @Find
    public List<Animal> findByEdadGreaterThanPagination(Long edad, Pagination pagination);

    @Find
    public List<Animal> findByEdadGreaterThanPaginationSorted(Long edad, Pagination pagination, Sorted sorted);

    @Ping
    public Boolean ping();

}

```

Los endpoints se definirían en la clase AnimalController, donde se inyecta el repositorio para consultar todos los documentos de la colección y realizar búsquedas por la llave primaria.

```java

@Path("animal")
public class AnimalController {

    @Inject
    AnimalRepository animalRepository;

    @GET
    @Produces({MediaType.APPLICATION_XML, MediaType.APPLICATION_JSON})
    public List<Animal> findAll() {
        return animalRepository.findAll();
    }
    

    @GET
    @Path("{idanimal}")
    public Animal findByIdanimal(@PathParam("idanimal") Long idanimal) {
      return animalRepository.findByPk(idanimal).orElseThrow(
          () -> new WebApplicationException("No hay animal con el id " + idanimal, Response.Status.NOT_FOUND));

    }
}

```

## Implementación de Paginación y Ordenación

La paginación es un método eficiente para gestionar operaciones con grandes volúmenes de documentos. Simplifica la recuperación de resultados manejables y facilita la navegación entre las páginas.

Por ejemplo, al buscar, 500000 documentos, cargarlos todos en memoria sería ineficiente si solo necesitamos visualizar los primeros 15. 

A través de la ordenación, determinamos la secuencia en la que se mostrarán los resultados.

Por favor, examine los métodos siguientes:

```java

@Find
public List<Animal> findByEdadGreaterThanPagination(Long edad, Pagination pagination);


@Find
public List<Animal> findByEdadGreaterThanPaginationSorted(Long edad, Pagination pagination, Sorted sorted);

```



Vamos a añadir un nuevo método en la clase AnimalController, el cual será responsable de recibir los parámetros y transferirlos al repositorio correspondiente.

```java

@Path("/ordenado")
@GET
@Produces(MediaType.APPLICATION_JSON)
public List<Animal> findByIdpersonaGreaterThanPaginationSorted(@QueryParam("edad") Integer edad, @QueryParam("pagina") Integer pagina, @QueryParam("registrosporpagina") Integer registrosporpagina,
    
   @QueryParam("orderby") String orderby) {
   List<Animal> animalList = new ArrayList<>();

   Sorted sorted = new Sorted(new Document(orderby, -1));

   Pagination pagination = new Pagination(pagina, registrosporpagina);
   animalList = animalRepository.findByEdadGreaterThanPaginationSorted(JmoordbCoreUtil.integerToLong(edad),
            pagination, sorted);
    return animalList;
}

```

## JmoordbCorePageUtil


Es una clase diseñada para facilitar operaciones relacionadas con paginación.

El método numberOfPages() toma dos parámetros: el total de registros y el número de filas por registro, y devuelve el total de páginas:

```java

Long count = personaRepository.count();
            
Integer numberOfPage = JmoordbCorePageUtil.numberOfPages(JmoordbCoreUtil.longToInteger(count), 25);

```

Se utiliza en combinación con un objeto de tipo Pagination, como en el caso de especificar la página 5 con 25 filas por página:

```java

  Pagination pagination = new Pagination(5, 25);

```


Para desplazarse entre las páginas, utilice los siguientes métodos:

* first: Este método le lleva a la primera página.

* last: Este método le lleva a la última página.

* next:Este método le lleva a la siguiente página.

* back: Este método le lleva a página anterior.



```java

 pagination = JmoordbCorePageUtil.first(pagination);
 pagination = JmoordbCorePageUtil.last(pagination);
 pagination = JmoordbCorePageUtil.next(pagination);
 pagination = JmoordbCorePageUtil.back(pagination);

```
